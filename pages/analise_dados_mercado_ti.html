Análise de dados no mercado de TI

Uma introdução ao que é a análise de dados, por que as empresas investem nela e como dar os primeiros passos usando Python.

O que é?

Análise de dados é o processo de coletar, organizar, examinar e interpretar dados para responder perguntas e apoiar decisões. Em vez de decidir "no achismo", usamos os dados para entender o que aconteceu, por que aconteceu e o que provavelmente vai acontecer.

Um dado, sozinho, é só um registro: um número de vendas, a data de um acesso, o peso de um animal. Quando juntamos muitos registros e fazemos as perguntas certas, eles viram informação útil.

Para que serve?

A análise de dados ajuda a:

  • Descrever uma situação: quanto vendemos no último mês?
  • Diagnosticar problemas: por que as vendas caíram em uma região?
  • Prever tendências: quanto devemos vender no próximo trimestre?
  • Recomendar ações: em qual produto vale a pena investir?

Em resumo, ela transforma dados brutos em respostas que ajudam pessoas e empresas a tomar decisões melhores.

Como é feito?

De forma simplificada, uma análise segue estas etapas:

  1. Definir a pergunta que queremos responder.
  2. Coletar os dados (planilhas, bancos de dados, APIs etc.).
  3. Limpar os dados: tratar valores faltando, erros e duplicados.
  4. Explorar os dados com estatísticas e gráficos.
  5. Comunicar os resultados de forma clara.

As principais bibliotecas Python

  • pandas: lê e manipula tabelas de dados (os DataFrames).
  • NumPy: faz cálculos numéricos de forma rápida; o pandas é construído sobre ele.
  • Matplotlib: a biblioteca base para criar gráficos.
  • Seaborn: cria gráficos estatísticos bonitos com pouco código, e já traz alguns datasets de exemplo.

Para instalar todas de uma vez, no terminal:

pip install pandas numpy matplotlib seaborn

Nosso dataset: os pinguins de Palmer

Vamos usar um conjunto de dados com medidas de 344 pinguins de três espécies (Adelie, Chinstrap e Gentoo), coletados em três ilhas da Antártida. O Seaborn carrega esse dataset direto da internet, sem precisar baixar nenhum arquivo: 

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

pinguins = sns.load_dataset("penguins")

# mostra as 5 primeiras linhas da tabela
print(pinguins.head())

Cada linha é um pinguim, e cada coluna é uma característica dele:

  • species: espécie
  • island: ilha onde foi observado
  • bill_length_mm e bill_depth_mm: comprimento e altura do bico (mm)
  • flipper_length_mm: comprimento da nadadeira (mm)
  • body_mass_g: massa corporal (g)
  • sex: sexo

Primeiras perguntas aos dados

# quantas linhas e colunas existem?
print(pinguins.shape)          # (344, 7)

# quantos pinguins de cada espécie?
print(pinguins["species"].value_counts())

# estatísticas das colunas numéricas (média, mínimo, máximo...)
print(pinguins.describe())

# existem valores faltando?
print(pinguins.isna().sum())

Repare que algumas colunas têm valores faltando (NaN). Tratar esse tipo de problema é o papel da limpeza de dados, assunto de um próximo artigo.

Agrupando e comparando

Qual espécie é a mais pesada, em média?

media_massa = pinguins.groupby("species")["body_mass_g"].mean()
print(media_massa.round(1))

# species
# Adelie       3700.7
# Chinstrap    3733.1
# Gentoo       5076.0

Visualizando

Um gráfico muitas vezes mostra em segundos o que uma tabela esconde:

sns.scatterplot(data=pinguins, x="flipper_length_mm", y="body_mass_g", hue="species")
plt.title("Nadadeira x massa corporal por espécie")
plt.show()

No gráfico, fica claro que pinguins com nadadeiras maiores tendem a ser mais pesados, e que os Gentoo formam um grupo separado das outras duas espécies.

Utilidade no mercado de trabalho

Praticamente toda empresa gera dados: vendas, acessos a um site, chamados de suporte, estoque. Por isso, quem sabe transformar esses dados em respostas é procurado em áreas como varejo, bancos, saúde, logística e tecnologia.

Algumas carreiras da área:

  • Analista de dados: responde perguntas do negócio com consultas, planilhas, gráficos e relatórios.
  • Analista de BI (Business Intelligence): constrói painéis (dashboards) para acompanhar indicadores.
  • Engenheiro(a) de dados: cria a estrutura que coleta, armazena e organiza os dados.
  • Cientista de dados: usa estatística e aprendizado de máquina para fazer previsões.

As ferramentas mais pedidas nessas vagas costumam ser Python, SQL, planilhas (Excel ou Google Sheets) e ferramentas de visualização como Power BI ou Tableau. O que você aprende com pandas aqui é a base para todas elas.

Exercícios

Use o dataset penguins do Seaborn em todos os exercícios.

Exercício 1: Conhecendo a tabela

Carregue o dataset e descubra quantas linhas e quantas colunas ele possui.

Ver resposta 
import seaborn as sns

pinguins = sns.load_dataset("penguins")
print(pinguins.shape)   # (344, 7): 344 linhas e 7 colunas

Exercício 2: Pinguins por ilha

Quantos pinguins foram observados em cada ilha? Qual ilha tem mais registros?

Ver resposta 
print(pinguins["island"].value_counts())

# Biscoe       168
# Dream        124
# Torgersen     52
# Biscoe é a ilha com mais registros.

Exercício 3: A maior nadadeira

Qual espécie tem, em média, a maior nadadeira (flipper_length_mm)?

Ver resposta 
print(pinguins.groupby("species")["flipper_length_mm"].mean().round(1))

# Adelie       190.0
# Chinstrap    195.8
# Gentoo       217.2
# A espécie Gentoo tem a maior nadadeira média.

Exercício 4: Dados faltando

Qual coluna tem mais valores faltando? Quantos são?

Ver resposta 
print(pinguins.isna().sum())

# A coluna "sex" é a que tem mais valores faltando: 11.

Exercício 5: Desafio com gráfico

Crie um histograma da massa corporal (body_mass_g), separando as espécies por cor. O que o gráfico mostra?

Ver resposta 
import matplotlib.pyplot as plt

sns.histplot(data=pinguins, x="body_mass_g", hue="species")
plt.title("Distribuição da massa corporal por espécie")
plt.show()

Os Gentoo se concentram nas massas mais altas, enquanto Adelie e Chinstrap ficam bem parecidos entre si.
